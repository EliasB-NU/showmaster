# Security Policy

## Supported Versions

Check the currently supported versions
I only update stuff in the v2.3 version, if requested.
Since the V3 version is much more stable and has more features, 
you should not use v2.3 at all.
All versions below v2.3 will never be updated or even locked
at by me again xD.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| 2.^3.x  | Only if requested  |
| 1.x     | :x:                |
